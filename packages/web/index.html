Workflow

Three commands from your terminal.

Install

Install from npm or run it once with npx.

npm install -g preflightlaunch
Scan

Point Preflight at an iOS project, archive, IPA, or folder.

preflight scan ./MyApp.xcarchive
Update

Pull the latest maintained CLI and rule updates from npm.

preflight update

Coverage

Checks maintained for the parts Apple actually reviews.

  • Info.plist permissions and entitlement risks
  • Privacy manifest required-reason API coverage
  • Screenshot dimensions and missing storefront assets
  • Metadata, keywords, category, URL, and policy traps
  • IPA binary checks for frameworks, symbols, and export compliance
  • Local rejection-risk scoring with source-backed fixes

Trust model

Your app stays on your machine.

The npm package runs the scanner locally with rules maintained from this repo and prints findings directly in your terminal. Your project files stay on your machine.
